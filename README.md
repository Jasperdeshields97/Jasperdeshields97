# Jasper DeShields

I build products from zero to revenue, and systems that run them with minimal human input.

Right now that is a small portfolio of health and content businesses operated by software I built:

**Jarvis Mission Control** (private repo)
Operations dashboard for my brands. Next.js, TypeScript, PostgreSQL, Redis. Cross-brand scoreboards, a content review queue, pipeline heartbeat monitoring, and a daily performance digest delivered to Telegram. House rule: a pipeline that doesn't heartbeat doesn't ship.

**Autonomous content engine** (private repo)
Python pipelines on a self-managed Linux server that draft, review-gate, schedule, and publish content across 3 brands and 4 channels. The copy and design rules were derived by scraping and analyzing top competitors, then enforced as code.

**The Comeback Code** ([comebackcode.co](https://www.comebackcode.co))
A newsletter and article library whose production runs unattended: Python jobs draft, publish, and email three issues a week through the Ghost Admin API.

**North**
iOS dopamine detox app. Concept to App Store submission in 7 days, privacy-first by architecture.
